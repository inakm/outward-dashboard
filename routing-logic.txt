Every outward order is assigned one of 7 routes (R1–R7) through
a 3-tier cascade. The first matching tier wins.


TIER 1: HARDCODED OVERRIDE (branchRouteOverride)
------------------------------------------------

TIER 2: ROUTE PLAN LOOKUP (routeFromBranch → branchInfo)
---------------------------------------------------------
The Branch name is matched against the 402-record R1–R7 plan
(embedded in route-plan.js, sourced from routes-planning.xlsx).

The matching is TOLERANT — trailing noise tokens are stripped
and retried:

  Noise tokens stripped: Branch, Brach, Floor, Road, Rd, No,
                         and numeric ordinals (1st, 2nd, 3rd…).

  Example flow:
    "Abids Branch"           → strip "Branch"   → "Abids"     → R3
    "Jubilee Hills Rd No 45" → strip tokens     → "Jubilee Hills" → R4
    "AJC 2nd Floor Branch"   → strip "2nd Floor Branch" → "AJC" → match

TIER 3: CUSTOMER MASTER PRIMARY ZONE (enrichRoutesFromMaster)
--------------------------------------------------------------
Fallback for orders whose Branch didn't match tiers 1 or 2.
Looks up the customer in the master sheet by tolerant name
matching (exact → case-insensitive → phrase → first-token),
then reads the Primary Zone field.

  Primary Zone           → Route
  ──────────────────────────────
  North-East             → R1
  North-West             → R2
  South-East             → R3
  South-West             → R4
  Outside Hyderabad      → R5
  Madhapur               → R6
  Outside Telangana      → R7

ADDING NEW LOCATIONS
---------------------

To add a new location that isn't in the route plan:

1. For special cases or overrides → add to BRANCH_ROUTE_OVERRIDE
   in script.js (Tier 1). Key must match cleanPlace() output
   (title-cased). Case-insensitive fallback is included.

2. For Hyderabad localities → add to routes-planning.xlsx
   and regenerate route-plan.js via ghmc-routing/build_route_plan.py

3. For spelling variations → add to PLACE_TYPO_MAP in script.js
   to normalize before lookup.

NOTE: Kukatpally, KPHB, Suchitra, RC Puram, and Visakhapatnam
are already covered by the route plan (Tier 2). They do NOT
need override entries unless you want to force a different route.
